# miuglitch-site

Static one-page site for Miu (miuglitch). Plain HTML and CSS with no build step: the files at the repo root are the site.

- `index.html`, `404.html`, `styles.css`: the page
- `img/`, `fonts/`, `icons/`: optimized images, self-hosted fonts, app icons
- `_headers` / `.htaccess`: security and caching headers (use whichever your host reads)
- `docs/launch-checklist.md`: launch checklist with done / to-do status

Preview locally: open `index.html`, or run `python3 -m http.server` in this folder.
